# LIVEPULSE INTELLIGENCE — وثيقة موثوقية وجودة البيانات المركزية (Data Confidence Ledger)

## 1. فلسفة سجل الثقة
في منصة **LIVEPULSE INTELLIGENCE**، لا يتم عرض أي رقم أو مؤشر دون تحديد مصدره، طريقة قياسه، ومستوى ثقته.
الهدف هو القضاء التام على ظاهرة "الأرقام الوهمية" أو التخمين غير المبرر الشائع في أدوات التحليل السطحية.

## 2. حالات الثقة المعيارية (Confidence States)
1. **VERIFIED (موثوق ومكتمل):**
   - البيانات مستلمة بالكامل وموثقة بمعاملات قطعية (مثل نقاط النزالات المحفوظة، وتاريخ منح واستهلاك الأدوات في الخزينة).
2. **PARTIAL (مكتمل جزئياً):**
   - البيانات سليمة ومؤكدة للفترة التي كان فيها موصل البث متصلاً، ولكن حدث انقطاع مؤقت أو تأخر في وصول بعض الأحداث.
3. **ESTIMATED (تقديري موثق المنهجية):**
   - مقياس مشتق من نشاط سلوكي مرصود (مثل دقائق الحضور المشتقة من فترات أول وآخر تفاعل مرصود للمستخدم).
4. **OUTDATED (يتطلب تحديث):**
   - مؤشر لم يستقبل أحداثاً حديثة منذ فترة زمنية محددة أو في انتظار إعادة تشغيل الجلسة.
5. **INSUFFICIENT_DATA (أدلة غير كافية):**
   - مؤشر لا يملك عينة إحصائية كافية (مثل محاولة تحديد أفضل ساعة للبث استناداً إلى جلسة واحدة فقط).

## 3. التكامل البرمجي (Unified Confidence API)
يوفر النظام واجهة برمجية موحدة تُرفق مع كل استجابة إحصائية:
```typescript
export interface MetricConfidence {
  metricName: string;
  source: 'TIKTOK_WEBCAST' | 'INTERNAL_LEDGER' | 'COMPUTED_DERIVED';
  methodology: string;
  confidenceState: 'VERIFIED' | 'PARTIAL' | 'ESTIMATED' | 'OUTDATED' | 'INSUFFICIENT_DATA';
  sampleSize?: number;
  coveragePercentage?: number;
  lastUpdated: string;
  limitations?: string;
}
```
يتم عرض هذه البيانات عبر شارة تفاعلية أنيقة بجانب كل بطاقة رقمية في الواجهة تمكن المستخدم من معرفة الحقيقة الكامنة وراء الرقم.

# LIVEPULSE INTELLIGENCE — وثيقة مواصفات المنتج (Product Specification)

## 1. الرؤية العامة والهدف
**LIVEPULSE INTELLIGENCE** هي منصة ذكاء أعمال ومراقبة حية لبثوث TikTok LIVE والمنافسات (1v1 و 2v2)، مصممة بهندسة برمجية متينة متعددة المستأجرين (Multi-Tenant SaaS).
تهدف المنصة إلى تمكين صناع المحتوى (الستريمرز) ومديري أعمالهم من تحويل تدفقات الأحداث الحية غير المهيكلة إلى ذكاء حقيقي قابل للتنفيذ:
- مراقبة اللحظة بلحظة للنزالات ونقاط الدعم.
- إدارة دقيقة لخزينة أدوات الداعمين (القفازات والضباب) مع تتبع الصلاحيات ومنع الاستهلاك المزدوج.
- تحليل سلوكي متقدم للداعمين والمجتمع دون تلفيق أرقام أو تخمين غير موثق.
- سجل شفاف لموثوقية وجودة البيانات (Data Confidence Ledger).

الحساب التشغيلي المرجعي الأول: `@mohra.2000` (مع دعم كامل لربط حسابات ستريمرز متعددين ومستأجرين مستقلين دون hardcoding).

## 2. النطاق الوظيفي والصفحات (Functional Scope)

| المسار | الاسم | الوظيفة الأساسية |
| :--- | :--- | :--- |
| `/` | النظرة العامة وغرفة المراقبة | لوحة المؤشرات الحية، حالة الاتصال بالبث، الأحداث الآنية. |
| `/inventory` | خزينة الأدوات الذكية | تتبع منح الأدوات (القفاز، الضباب)، الرصيد، الاستهلاك، تنبيهات الانتهاء (5 أيام). |
| `/battles` | غرفة النزالات 1v1 و 2v2 | عرض النزالات الحية والسابقة، مطابقة الفرق، توزيع نقاط الداعمين وتغير النتيجة. |
| `/supporters` | ذكاء الداعمين | تصنيف الداعمين بناءً على سلوكهم، تتبع نشاطهم، تاريخ الدعم، وتحليل الاتجاهات. |
| `/enigmas` | الحسابات الغامضة (Enigma) | فحص احتمالية ارتباط حسابات متعددة لنفس الداعم بناء على أدلة موثقة (SecID، المعرفات). |
| `/analytics` | التحليلات الزمنية وجودة التوقيت | تحليل الأداء بالساعة واليوم (Asia/Riyadh)، مؤشر جودة وقت البث. |
| `/champions` | أبطال المجتمع | نظام تقييم متوازن ومتعدد الأبعاد (حضور، تعليقات، لايكات، مشاركات) مع شرح النتائج. |
| `/stream-memory` | ذاكرة البث | خط زمني تاريخي مترابط يجمع كل جلسة بث بنزالاتها وداعميها وأدواتها وتقاريرها. |
| `/community-map` | خريطة المجتمع | رسم بياني تفاعلي يوضح العلاقات السلوكية المثبتة (مشاركات مشتركة، تفاعل متبادل). |
| `/reports` | التقارير والذكاء الاصطناعي | تقارير إحصائية دورية + تفسير تحليلي وتوصيات بالذكاء الاصطناعي (مع حظر توليد الأرقام). |
| `/settings` | الإعدادات والتكاملات | إدارة المستأجرين، ربط حسابات TikTok، الصلاحيات، كتالوج الأدوات، مفاتيح الربط. |
| `/onboarding` | التسجيل والإعداد | معالج تهيئة الستريمر الجديد وإعداد القنوات. |

## 4. القيود الهندسية غير القابلة للتفاوض
1. **عزل المستأجرين (Tenant Isolation):** كل استعلام وتحديث مفصول بمعرف الـ `tenantId`.
2. **منع الأرقام الوهمية:** محرك البيانات يحسب الأرقام، ولا يقوم الذكاء الاصطناعي باختراع إحصائيات.
3. **طبقة الثقة بالبيانات (Confidence Ledger):** توثيق مصدر وطريقة قياس وحالة اكتمال كل مقياس يظهر في المنصة.
4. **التوقيت الرسمي:** التخزين الداخلي بـ UTC، والعرض والتحليل الزمني والتقارير بتوقيت الرياض (`Asia/Riyadh`).
5. **منع الاستهلاك المزدوج للأدوات:** عمليات ذرية (Database Transactions & Atomic Decrements) مع تتبع رقم الدفعة والحدث.

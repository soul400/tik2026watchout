# LIVEPULSE INTELLIGENCE — سياسات الأمن وحماية البيانات (Security & Privacy)

## 1. نموذج عزل المستأجرين (Tenant Isolation Model)
- تطبيق **Logical Multi-Tenancy with Strict Scoping**: كل جدول تشغيلي يحتوي على عمود `tenant_id` غير قابل للتفريغ (`NOT NULL`).
- التحقق الإلزامي من الـ `tenant_id` في طبقة الـ Data Access Layer (Prisma Client Middleware / RLS policies).
- استحالة استعلام أو تعديل أي سجل ينتمي لمستأجر آخر من خلال معرف الجلسة الموثقة (Session Tenant Context).

---

## 2. إدارة الصلاحيات والأدوار (Role-Based Access Control - RBAC)
1. **Platform Administrator:** إدارة المنصة والبنية التحتية والمستأجرين.
2. **Streamer Owner:** مالك الحساب (كامل الصلاحيات داخل مساحة المستأجر الخاصة به).
3. **Streamer Manager:** مدير البث (إدارة الخزينة، تصحيح نتائج الجولات، جدولة التنبيهات).
4. **Read-only Analyst:** محلل قراءة فقط (استعراض التحليلات والتقارير دون إمكانية التعديل).

---

## 3. حماية البيانات والخصوصية
- تشفير البيانات أثناء النقل (TLS 1.3) وأثناء التخزين.
- عدم كشف معرفات TikTok الحساسة أو التوكنات في واجهات الـ Frontend العامة.
- عدم تخمين الهويات الحقيقية للأشخاص في أدوات Enigma أو Community Map؛ فكافة التحليلات مبنية حصراً على المعرفات السلوكية العامة الظاهرة في البث.
- حماية مسارات الـ API بمحددات معدل الطلبات (Rate Limiting) لمنع الإغراق.
- سجل تدقيق شامل (`AuditLog`) يسجل أي تصحيح يدوي لنتائج الجولات أو استهلاك الأدوات مع هوية المستخدم والوقت والسبب.
